# Streamline Logging While Preserving Back-Compat

1. prefer-v13-apis-with-fallback

- Rationale: Foundry v13 expects `foundry.applications.apps.DocumentSheetConfig`; falling back to the global only when necessary removes repeated compatibility warnings while keeping older cores working. We’ll cache the resolved ref so later calls reuse it without extra lookups.
- Actions: update `src/modules/document-sheet-config.js`, then replace direct `DocumentSheetConfig` checks in `src/modules/anarchy-system.js` and `src/modules/ui-customization-commands.js` with the cached helper.

2. wrap-handlebars-loaders

- Rationale: several modules still call global `loadTemplates`/`renderTemplate`, triggering deprecation logs. A single helper that prefers `foundry.applications.handlebars.*` keeps code lean and compatible.
- Actions: add `src/modules/handlebars-utils.js` exposing `loadTemplatesSafe`/`renderTemplateSafe`, then switch callers in roll, GM, HUD modules to use the helper.

3. verify-prod-mode

- Rationale: ensures the cleaned logging actually works, both in v13 and in legacy fallbacks.
- Actions: rebuild, reload Foundry, confirm `Anarchy | Sheets registered` fires without compatibility warnings and new actors/items open the enhanced sheet.
